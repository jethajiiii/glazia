# GLAZIA / WINDOORS - Mini Design Canvas

> Technical Assignment: Full Stack Developer Internship

An interactive 2D canvas editor that allows users to create, manipulate, customise, save and reload graphical designs.

## Tech Stack
- **Frontend**: React 18, React Konva, Konva.js, Zustand, Vite
- **Backend**: Node.js, Express.js (ES Modules), Zod, Helmet, Morgan
- **Database**: MongoDB (Mongoose)
- **Tooling**: ESLint 9, Prettier, Nodemon
